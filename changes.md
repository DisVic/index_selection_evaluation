# Описание изменений в коде проекта (changes.md)

В рамках работы по развертыванию бенчмарка TPC-DS под три разные парадигмы (Kimball, Inmon, Data Vault 2.0) была подготовлена инфраструктура базы данных. 
Так как этот репозиторий является фреймворком `index_selection_evaluation`, в сам код драйверов фреймворка мы **не вносили изменения**, так как наша зона ответственности ограничивается развертыванием БД. Тем не менее, для удобства использования мы добавили в корень проекта следующие вспомогательные файлы:

1. **Базовый DDL и ETL:** добавлены файлы `load_data.sql`, `create_inmon_ddl.sql`, `create_inmon_etl.sql`, `dv_ddl.sql`, `dv_etl.sql`, организующие структуру и трансформацию 1.3 ГБ сырых данных (загруженных из `tpcds_data_1`).
2. **Docker Compose:** добавлен файл `docker-compose.yml` для автоматического и гарантированного развертывания PostgreSQL в контейнере.
3. **Автоматизация деплоя:** скрипты `deploy.bat` и `deploy.sh` (вместе с гайдом `deploy_guide.md`) для полностью автоматической распаковки многотомных архивов (например, `tpcds_data_1.zip`) и последовательного наката DDL/ETL для всех трёх парадигм.
4. **.gitignore:** Добавлено игнорирование логов запуска, временных SQL-файлов и архивов с данными, чтобы не засорять репозиторий "мусором" и тяжеловесными артефактами.

Всё остальное в оригинальных коннекторах и парсерах (`selection/`) оставлено нетронутым.
